# Film

A narrated film rendered from HTML. `scene.html` is the picture: every frame
is a pure function of time (`window.render(t)`). Headless Chrome steps it frame
by frame and the bundled ffmpeg encodes it. Scaffolded by the
[brand-film](https://github.com/davidscotttufts/brand-film) skill.

| File | What |
|---|---|
| `brand-tokens.json` | the film design system: colours, type, logos, narrator, pronunciation lexicon. Keys it leaves out inherit `default-tokens.json` |
| `brand-tokens.css` | generated by `npm run tokens`; the scene links it and uses only `--video-*` |
| `scene.html` | the scene: timings, `INSERTS`, sound-effect cues (`SFX`) |
| `narration.json` | the voice-over: one take per scene, each with the window it must finish inside |
| `narrate.mjs` | voices changed takes, checks each by speech-to-text, writes `narration/manifest.json` and `takes.lock.json`; `--audition` compares voices |
| `lint.mjs` | checks the narration with no API: windows, sentence length, acronyms, digits |
| `music.json`, `music.mjs` | the optional score (ElevenLabs music, instrumental); `music.lock.json` records how it was made |
| `sfx.json`, `sfx.mjs` | six effects synthesized with ffmpeg into `sfx/` |
| `film.json` | the scene file, the output name, the source text and the facts it must match |
| `render.mjs` | writes `out/<basename>.mp4`, the poster, `.en.vtt` captions and a `.report.json`, and verifies the file |
| `preview.mjs` | single frames (`npm run preview -- 12.5 60`) or a contact sheet (`npm run sheet`) |
| `doctor.mjs` | checks Node, the packages, Chrome and the ElevenLabs sign-in |

```bash
npm install
npm run doctor             # what's missing, if anything
npm run tokens             # check the brand, write brand-tokens.css
npm run lint               # check the narration (no API)
npm run narrate            # voices only changed takes, and listens to each
npm run music              # only recomposes when music.json changes
npm run sfx
npm run sheet              # review frames before the long render
npm run render
```

The audio is generated, not committed. `takes.lock.json` and
`music.lock.json` record how each piece was made (model, voice, settings, the
exact text, the listening check, the plan), and `narration/manifest.json` keeps
the word timings, so a clone without the audio still renders, silent, with the
same captions.

The mix: narration normalized to -16 LUFS with a -1.5 dBTP ceiling on its own
bus; effects 12 dB or more under the voice; the score (if any) about -10 dB,
ducked under the narrator by a sidechain compressor, with a fade in and out.

When you change a line in `narration.json`, re-run `npm run narrate` and move
the matching cues in `scene.html` to the new word times in
`narration/manifest.json`. Every fact on screen comes from `film.json` `source`.
